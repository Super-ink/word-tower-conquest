# 词塔征服 · Word Tower Conquest

一个用 HTML/CSS/JS 制作的 Roguelike 背单词游戏。

## 玩法
- 爬塔地图：战斗、休息、事件、Boss
- 英汉连线战斗，正确拼写造成更高伤害
- 在营地掌握单词，通过考核获得永久增益
- 三层词汇难度（四级 / 六级 / 考研）

## 在线游玩
